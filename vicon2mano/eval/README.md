# Evaluation figures

Two figure sets, regenerated 2026-06-12 against the real recording
`data/Pxh8/Hands_only_Left/trajectories_synced.csv` (55,832 frames, left hand).

## `fit/` — end-to-end fit performance (the working pipeline)

Generated by [`scripts/eval_fit.py`](../../scripts/eval_fit.py) from the fit
output `data/Pxh8/Hands_only_Left/mano_fit_left.npz`.

```bash
python scripts/eval_fit.py \
    --npz data/Pxh8/Hands_only_Left/mano_fit_left.npz \
    --csv data/Pxh8/Hands_only_Left/trajectories_synced.csv \
    --out-dir vicon2mano/eval/fit
```

| File | Shows |
|---|---|
| `fit_fig1_residuals.png` | Per-joint marker→fitted-joint distance + residual histogram. **Overall mean 22.8 mm, median 21.4 mm** across all 55,832 frames; 16/21 joints matched (the 5 fingertips are unobserved). |
| `fit_fig2_residual_time.png` | Mean residual over the whole recording — stays ~15–35 mm throughout. |
| `fit_fig3_overlays.png` | 3-D overlays at 6 evenly-spaced frames: Vicon markers (gray) + fitted MANO skeleton (coloured per finger) + assignment links. The recovered skeleton is anatomically correct in every frame. |

Residuals in the 15–25 mm range are expected: markers sit on the skin surface,
not at joint rotation centres. The assignment here comes from the **label-seed**
path (clean_kinematics labels recognised after normalisation), not the CNN.

## `deep_labeler/` — CNN labeler diagnostics

Generated by [`scripts/eval_labeler.py`](../../scripts/eval_labeler.py).

```bash
python scripts/eval_labeler.py \
    --real-data data/Pxh8/Hands_only_Left/trajectories_synced.csv \
    --out-dir vicon2mano/eval/deep_labeler
```

| File | Shows |
|---|---|
| `fig1_training_curves.png` | Focal-BCE train/val loss + cosine LR (best val 0.0156 @ epoch 19). |
| `fig2_joint_performance.png` | **Documents why the CNN is not trusted:** ~100% assignment rate but ≈0% within 10 mm of GT, 65–140 mm mean error, confidence clustered at 0.4–0.5 (confidently wrong). The checked-in `deep_labeler.pt` is a 500-frame smoke-test checkpoint. |
| `fig3_3d_overlays.png` | 3-D Vicon/skeleton overlays from the raw CNN assignment. |

The `frame_*_raw.png` / `frame_*_pxh8.png` files are older ad-hoc snapshots with
no generating script and are not part of either pipeline.
